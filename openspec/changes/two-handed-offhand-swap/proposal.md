# Proposal

Allow hand-slot equipment swaps across the two-handed/one-handed boundary.

When a two-handed weapon is equipped, equipping an off-hand item should automatically move the two-handed weapon back to inventory and leave mainHand empty. Conversely, equipping a two-handed weapon should automatically move any off-hand item back to inventory.

The same compatibility behavior must apply to staged equipment changes while grinding, where the actual loadout changes at the next authoritative battle boundary.
