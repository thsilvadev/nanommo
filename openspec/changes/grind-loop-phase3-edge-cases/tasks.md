# Tasks

Reference: `specs/grind-loop-verification/spec.md` for the guarantees, `design.md` for the approach (D1–D8 and the four known divergences).

**Standing constraints for every task below:**
- No production code changes. Where an assertion fails, determine from `design.md` "Known divergences" whether it is a divergence to document (expected) or a real regression (report, do not fix here).
- No new npm dependencies.
- Backend base URL comes from `process.env.PHASE3_API_URL`, defaulting to `http://localhost:3010` (the docker-compose host mapping). `test-s63.js` hardcodes `3000`; the new scripts must not repeat that.

**Prerequisite (run once before any stack-dependent task):**

```bash
# Rebuild shared + api. Required: STATUS.md §0 records that a stale
# packages/shared/dist silently breaks battle-engine imports.
pnpm build
grep -c "exports.mulberry32Seed" packages/shared/dist/battle-engine/prng.js   # must be >= 1

# Start the stack and wait for readiness.
docker compose up --build -d
# Readiness probe: any HTTP status (401 is fine and expected) means routing is live.
until [ "$(curl -s -o /dev/null -w '%{http_code}' http://localhost:3010/maps)" != "000" ]; do sleep 2; done
```
