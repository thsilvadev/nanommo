🔑 KEY PRINCIPLES

✓ Craft (1-6/1-10):     Genérico, afeta múltiplos cálculos
✓ Drop (5-12/80-200):   Específico, 2.5x mais valioso
✓ Growth:               T1→T2: 1.6x | T2→T3: 1.5x
✓ HP > SP:              Sempre 2x maior
✓ Defense ≈ ATK:        Balanço ofensivo/defensivo
✓ No Regen:             Sem HP/SP regen nas pools

📊 WHEN TO USE WHAT

CRAFT:
  • Player crafts equipment
  • Add random attribute (STR, AGI, etc)
  • Use randomRollOnCraft config

DROP:
  • Monster drops equipment
  • Add random specific stat (ATK, HP, etc)
  • Use randomRollOnDrop config
