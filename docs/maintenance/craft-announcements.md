# Anúncios globais de craft

Remova IDs de `craft_announcements.json` para desabilitar anúncios de itens comuns. Todos os produtos das receitas atuais começam habilitados. A configuração é lida no início da API. O canal Crafts pode ser ocultado pelo jogador e mantém as últimas 40 mensagens no Redis. Cada unidade concluída gera um anúncio.
